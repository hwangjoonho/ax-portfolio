Overview
한 번의 push, 8대 동시 검증

맥미니에 연결된 실물 단말 8대(iOS 1 + Android 7)를 디바이스팜으로 묶고, 앱 저장소의 테스트 브랜치에 커밋을 push하면 빌드부터 8대 동시 E2E 테스트, 결과 리포트까지 사람 손 없이 흘러갑니다. 디바이스 화면은 GADS 웹 UI로 실시간 모니터링합니다.

네트워크 우회 — Agent Pull 모델. Jenkins 컨트롤러(지원서버)와 맥미니는 서로 다른 L2 네트워크에 있어 컨트롤러가 맥미니로 직접 접속(SSH push)할 수 없습니다. 그래서 맥미니가 외부 도메인(HTTPS)으로 컨트롤러에 붙는 Agent pull 방식으로 전환해, 빌드 잡이 맥미니 위에서 실행되도록 했습니다.
Devices
8대 동시 실행 구성

8대를 라운드로 쪼개지 않고 단일 wave parallel block으로 한 번에 spawn해 동시 실행합니다. iOS 1대 + Android 7대가 같은 빌드 사이클에서 함께 테스트됩니다.

Features
핵심 포인트
01
Agent Pull 통신 모델
컨트롤러↔맥미니 L2 격리로 SSH push 불가. 맥미니가 외부 도메인(HTTPS)으로 Jenkins에 붙어 빌드 잡을 끌어오는 방식으로 우회.
02
8대 Single-Wave 병렬
라운드 분할 없이 8대(iOS 1 + Android 7)를 단일 parallel block으로 동시 spawn. 전체 테스트가 한 wave에서 끝납니다.
03
WDA 자동 재빌드
무료 Apple 계정의 7일 프로파일 만료에 대응해, LaunchAgent가 WebDriverAgent를 주기적으로 자동 재빌드합니다.
04
JUnit XML 결과 수집
Patrol 테스트 결과를 표준 JUnit XML로 출력해 Jenkins가 자동 파싱. 단말별 pass/fail을 한눈에 집계합니다.
05
GADS 실시간 모니터링
8대 단말 화면을 GADS 웹 UI로 실시간 확인. 별도 미러링 인프라 없이 디바이스팜 기본 기능을 그대로 활용합니다.
06
LaunchAgent 무중단 운영
hub / provider / healthcheck / wda-rebuild / jenkins-agent 5종 LaunchAgent로 맥미니 부팅 시 디바이스팜이 자동 기동됩니다.
